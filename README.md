# Recondition House – GitHub Pages setup
1. Create a PUBLIC repo, upload everything in this folder (keep the folders: css, js, data, images).
2. Settings > Pages > Deploy from branch > main / root. Site: https://USERNAME.github.io/REPO/
3. Settings (profile) > Developer settings > Fine-grained tokens > only this repo > Contents: Read and write. Set expiry 14 days.
4. Open /admin.html, paste the token, add vehicles. Customers use /index.html.
5. After 1-2 weeks: revoke the token and delete the repo (or turn off Pages).
